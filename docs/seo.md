# SEO Notes

## Search Console Setup

After deployment, set up Google Search Console for `https://guestography.com`.

1. Add the domain or URL-prefix property.
2. Complete ownership verification using the method Google recommends for the deployed host.
3. Submit `https://guestography.com/sitemap.xml`.
4. Inspect `/`, `/event`, `/blog`, and several blog post URLs.
5. Review query impressions monthly and use them to choose the next posts.

## Content Pattern

Guestography blog posts should usually include:

- a search-focused title
- comparison of realistic options
- internal links to related event guides
- a short FAQ section
- a final Guestography CTA linking to `/`

Prioritize clusters around weddings, birthdays, fundraisers, corporate events, school events, reunions, and holiday parties.
