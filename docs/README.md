# Repository Knowledge Base

This `docs/` directory is the system of record for agent-readable context in this repository.

## Index

- [`architecture.md`](./architecture.md): current application boundaries, major modules, and integration points
- [`development.md`](./development.md): local setup, validation, and deployment-adjacent workflows
- [`product.md`](./product.md): product intent inferred from the current codebase
- [`automation.md`](./automation.md): agent harness rules, GitHub workflows, and operating model
- [`exec-plans/README.md`](./exec-plans/README.md): execution-plan workflow for medium and large changes
- [`exec-plans/tech-debt-tracker.md`](./exec-plans/tech-debt-tracker.md): active debt items worth future agent work

## Usage

- Keep high-signal facts here instead of scattering them across issue comments or chat.
- Add or update docs when repository behavior changes in a way that future agents need to understand.
- Prefer short, navigable files over one large manual.
