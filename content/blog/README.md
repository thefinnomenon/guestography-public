# Blog Content Workflow

Add posts as `.mdx` files in this folder. Use a descriptive, keyword-focused filename because it becomes the URL slug.

Required frontmatter:

```md
---
title: "Wedding Photo Sharing Options: QR Code Gallery vs Shared Album"
description: "A short search-friendly summary."
publishedAt: "2026-07-09"
category: "Wedding Planning"
keywords:
  - wedding photo sharing
  - wedding QR code photos
---
```

Keep posts useful and narrow:

- Start with the search question in the title.
- Compare realistic options before pitching Guestography.
- Add a short checklist or decision guide.
- Link back to `/event` only where it naturally helps.
- Publish clusters of related posts, such as weddings, birthdays, fundraisers, reunions, and corporate events.
